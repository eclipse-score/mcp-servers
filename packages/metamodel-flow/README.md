# metamodel-flow

`metamodel-flow` delivers the normative S-CORE artifact model as an APM
instruction package. It commits the vendor-neutral projection generated by
`docs-as-code` and renders that projection into deterministic Markdown for
agents.

## Updating the model

When `docs-as-code` updates the metamodel:

1. Run `bazel run //src/extensions/score_metamodel/agent_context:generate_agent_context_bin -- --output /tmp/agent_context.json` from the `docs-as-code` workspace.
2. Copy the generated JSON verbatim to `model/agent_context.json` and update
   `model/source.txt`.
3. Run `python src/render_markdown.py --write`.
4. Commit both the model artifact and generated instruction Markdown.

The package tests compare the committed instructions against a fresh render, so
the existing `pytest` job in CI fails whenever projection and instructions
disagree. No workflow writes or commits generated files.

The MCP server for task-scoped trace checks follows separately.
